      Classic 0.13 return
      
Return from 1.x to Classic 0.13.0
        
Classic is no longer maintained. Reinstalling it alone does not restore your old music.
        Choose the complete Classic backup saved before upgrading and the original 0.13.0 firmware package.

        

        

        

        

        
The installer saves a Classic restore JSON file, including when you selected a ZIP backup.
        After installation, open that JSON file in the Classic editor to restore your music.
        Your 1.x backup can only be restored after reinstalling 1.x. The return requires a running 1.x device;
        interrupted updates use the recovery route separately.
