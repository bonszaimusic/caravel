# Project INIT and the global FX track

**Project INIT.** SAVE > PROJECT offers **INIT** on KNOB 2. OCT+ opens the confirmation and OCT+ again initializes the project without a reboot:
boot sounds, empty sequences and automation, project defaults. Stored A–D, USER sounds, FM6 banks, MIDI Learn mappings and device preferences stay.
KNOB 2 selects INIT, then ERASE on a second right turn (a left turn goes back to INIT, then deselects); both actions need their confirmation dialog.

**Global FX track.** MENU > AUDIO > **FX TRACK T1–T4** (default T1): that track records and replays global FX with its LEN / DIV, even while
another sound track is selected. The setting is saved with the project and the effects process the master mix. See
[FX-special automation](FX_SPECIAL_AUTOMATION.md).
