# Engine documentation

These guides answer **what an engine offers and how to use it**: sound features,
controls, presets, modulation, saving, compatibility and practical limits.

Source-code paths and commands are relative to the repository root unless
explicitly stated otherwise. Verification statements distinguish host tests
from physical FM-1 acceptance.

- [All engines at a glance](overview.md): what each of the engines is and what it is good for.
- [Tips and tricks](tips.md) for SEM, HADES and DRONE.
- [SEM](SEM_ENGINE.md): Oberheim SEM-inspired virtual analogue engine.
- [HADES](hades-engine.md): Hades-inspired bass engine, controls and limits.
- [ENSEMBLE](ensemble-engine.md): strings, choir and dark texture with a built-in ensemble (Caravel 0.10.0).
- [DRONE](../drone-engine.md) and its [cell modes](drone-cells.md): coupled generators, opt-in selective cells.

Historical components omitted from the 1.0 profile: [DRUM-X](drum-x.md), [PHASE feedback](morph-and-feedback.md) and [LOFI](lofi-byte-float.md). Their source and attribution remain documented; they are not current engine choices.
