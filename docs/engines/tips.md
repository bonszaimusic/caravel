# Starting points for the six engines

Use BUILD for setup and PLAY for performance. Start with one dry track at a low level; balance layers before adding delay, reverb or STASIS.

| Engine | First experiment | Next step |
| --- | --- | --- |
| ANALOG | Saw lead, low resonance, short release | Try PWM or a little filter-envelope movement |
| PHYS | One plucked note, moderate decay | Compare model and damping before adding FX |
| SEM | Soft pad; compare CUT with STATE | Add small detuning/vintage variation |
| HADES | MONO bass with one sub | Add BODY and drive gradually; check the mix level |
| DRONE | Quiet held note; one topology | Add drift, then compare cell modes |
| ENSEMBLE | Factory pad with modest ENS | Compare SPRD zero and stereo width; rebalance level |

For motion, put only intended targets in the track's own performance set and start RANDOM or ELASTIC with a small range. CAPTURE can repeat a live panel or MIDI note gesture while you shape timbre; it does not save audio or persist with the project.
