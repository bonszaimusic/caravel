# Six engines in Caravel 1.0

Select an engine with EDIT held in BUILD. PLAY / SOUND exposes four primary controls; EDIT groups expose the remaining controls. Envelope, track filter, ARP, modulation, harmony and FX are shared track facilities.

| Engine | Character | Start here |
| --- | --- | --- |
| ANALOG | Band-limited oscillators, sync, sub/noise and multimode filter | A simple lead or soft pad; moderate resonance |
| PHYS | Modal, string and membrane physical models | A mallet/pluck; compare decay before adding reverb |
| SEM | Detuned oscillators, blended LP/notch/HP state-variable filter | Warm pad; move CUT and STATE separately |
| HADES | Saw/pulse, two subs, three-pole bass filter, drive and BODY | Mono bass; add sub level gradually |
| DRONE | Coupled generators, drift, topology and cell modes | Quiet held note; change one topology control at a time |
| ENSEMBLE | Three registers and a built-in stereo ensemble | String/choir pad; compare width against mono |
